The framework (why it works)


**Hook ≤ 3s** — a question, a number or a conflict, never a greeting. **One idea per sentence** — captions and attention both break on long sentences. **The turn** at the midpoint re-opens curiosity exactly when swipe-away peaks. **The close** asks a question the viewer can answer in five words. Scripts land at 110–150 words: 45–60 seconds spoken.


The downloadable core (GitHub) does the same assembly offline and writes script.txt in the exact format the Talking-Head pipeline renders.
